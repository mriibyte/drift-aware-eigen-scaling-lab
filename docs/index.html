The mathematics behind the experiment

A two-dimensional quadratic has a moving minimizer and a changing positive-definite Hessian. Here are the objective, update rule, and adaptive step size.

01 · MOVING QUADRATIC OBJECTIVE
ft(x)=12(x−xt*)TAt(x−xt*)
02 · GRADIENT DESCENT UPDATE
xt+1=xt−ηt∇ft(xt)
03 · DRIFT-AWARE STEP SIZE
ηt=γ(1+s)λ^max,t

Notation: x*t = current minimizer; At = Hessian; ηt = step size; γ = eigen gain; s = safety margin; λ̂max,t = tracked largest eigenvalue.

  • Normal GD uses a fixed, unscaled η. It may track well with a conservative setting, or become unstable if curvature grows too much.
  • Frozen scaling uses λmax only at t = 0. Its step can become stale as the Hessian changes.
  • Drift-aware scaling uses power iteration and a smoothing filter. Relative spectral changes increase the filter response, and upward observations are accepted immediately.
  • Stability reasoning: for a fixed SPD quadratic, an eigen-direction has error multiplier 1 − ηλ. Requiring |1 − ηλ| < 1 for all directions gives 0 < η < 2 / λmax.

This is an educational heuristic, not a general convergence guarantee. Power iteration can underestimate λmax, so a safety margin does not certify stability. With a moving target the error also includes target drift. Neither method is guaranteed to win for every slider setting.
